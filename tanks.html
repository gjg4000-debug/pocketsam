Levels are estimates between readings. Each tank starts from its newest reading: a site visit, an Import levels from the monitoring export (a .csv file), or an Update level you type in. From there it counts down using the feed rate. It won't know about a Delta Dose, a pump losing prime, a leak, or a delivery until the next reading, so import often.
